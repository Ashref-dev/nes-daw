# NES DAW

Browser-based NES-style digital audio workstation for composing retro/chiptune music.

- Live app: https://daw.ashref.tn
- MIDI import and export
- Piano roll editing and arrangement tools
- Optional AI-assisted song generation with `GEMINI_API_KEY`

## Getting started

1. Install dependencies:
   `bun install`
2. Set the `GEMINI_API_KEY` in `.env.local` if you want to use AI generation.
3. Run the app:
   `bun run dev`

## Build

`bun run build`
